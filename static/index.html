Disease-to-Target Agent

Name a disease. An LLM agent searches recent PubMed papers, reads the abstracts and checks up to three candidate protein targets against UniProtKB, citing every source.

A run takes 10–40 seconds. Research use only: output is a hypothesis, not medical advice.
